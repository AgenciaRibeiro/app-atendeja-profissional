# Regra Permanente: Frontend UI Engineering Automático

Sempre que a tarefa envolver criar, alterar ou revisar qualquer elemento visual, HTML, CSS, JavaScript de interface, telas de onboarding, dashboard, admin, modais, componentes, menus, botões ou carrosséis:

- Aplique e consulte imediatamente a skill `frontend-ui-engineering` (`.agents/skills/frontend-ui-engineering/SKILL.md`).
- Assegure conformidade mobile-first, alvos de toque >= 44px, ausência de rolagem horizontal e fluidez nas animações.
